This plugin is use [PatPat Plugin API](https://github.com/nikita51bot/PatPat-Plugin-Api), it does two things:
- Adds the `/pat` command.
- With a random chance when patting a dog or cat, it may become tame and give the player an achievement.

This plugin was created to demonstrate the PatPat Plugin API.

Before installing, make sure:

1. PatPat Plugin v1.2.5 or higher is installed on the server.
2. Make sure it is working.
3. In the PatPat Plugin config, the `api` key is set to `true`.
